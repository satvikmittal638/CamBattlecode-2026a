# Official export refresh, 29 October 2026

The five official exports in `official/` were downloaded from the organisers' current documentation page. All 836 lines of `GameRules.md` were read, including all champion specifications. The C++ API sections relevant to v114 were checked against the local SDK. Checksums and download timestamps are in `FETCH_MANIFEST_2026-10-29.json`; the full export diff is in `analysis/v114_review_2026-10-29/official_exports.diff`.

The existing scraper completed the five downloads before it was stopped following the user's instruction to avoid browsers. Further work used the existing CLI, HTTP submission/replay scripts, and replay analysis scripts. Handbook pages and the patch-note index were not refreshed; use the official exports for current mechanics.

Changes relative to the previous canonical `official/GameRules.md`:

- First draft turn: 100× fuel, previously 10×. Normal C++/Rust turns remain 100,000 fuel, first champion turn 2×.
- Monster emblem: 15% extra camp damage, previously 10%.
- Treasure emblem: 10% extra gold, previously 20%; Vesper + Treasure now adds to 43%.
- Seven additional item families: Tribute, Capture, Prospector, Hunter, Skirmish, Greed, Collectors. There are 84 item types.
- Capture emblem caps the remaining capture countdown at three, including when joining an existing capture. The reduction persists while another ally holds the region.
- Prospector grants 25% extra on its owner's share of cluster gold/gems, floored independently. It does not increase the other capturers' shares.
- Greed combines at 25 matching shards (750 gold), providing 35 shards' stats.
- Tribute shortens tribute channels by 33%, rounded up to at least one turn. Hunter adds 50 base kill gold. Skirmish adds 5% champion damage. Collectors adds 1% damage per distinct completed family, including itself.
