## API additions

All four official API exports now document distance-field copying into existing storage:

| Language | Added methods |
| --- | --- |
| C++ | `distance_field::copy_from(source)` and `copy_from(source, mask)` |
| Python | `DistanceField.copy_from(source, mask=None)` |
| Rust | `copy_from(&source)` and `copy_from_with_mask(&source, &mask)` |
| OCaml | `Distance_field.copy_from ?mask destination source` |

Whole-field copying reuses destination storage. Masked copying preserves unselected destination values and ignores mask padding; self-copy is a no-op. Availability in the currently installed SDK was not established by fetching these docs.
